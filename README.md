About
PC File Arranger is a Python-based utility designed to simplify your digital life by automatically sorting files in a specified directory. It categorizes files based on their extensions and moves them into designated folders, helping you maintain a clean and organized file system. The tool is highly customizable, allowing you to define your own categories and file types via a configuration file.

Features
Organizes files by extension into user-defined categories

Supports dry-run mode to preview changes without moving files

Easy configuration for custom categories and extensions

Command-line interface for quick operation

Logs actions and errors to log files for easy troubleshooting

Getting Started
Prerequisites:

Python 3.x

pip (Python package manager)

Installation
Clone the repository:

bash
git clone https://github.com/yourusername/pc-file-arranger.git
Navigate to the project directory:

bash
cd pc-file-arranger
Install dependencies:

bash
pip install -r requirements.txt
